# Projects

## Introduction

In the MMRF Virtual Lab, data is organized at a high level by **project**. Each project represents a specific CoMMpass data release or dataset grouping and serves as the primary entry point for accessing associated files.

The **Projects page** provides a centralized view of all available datasets and allows users to explore, navigate, and access data within the platform.

---

## Projects Page Overview

The Projects page displays a table of available datasets, including:

- **Project ID** (e.g., MMRF-COMMPASS-IA24, MMRF-IA22)
- **Program** (e.g., MMRF)

Users can access the Projects page from the top navigation bar or from the Virtual Lab homepage under **Core Tools**.

---

## Project Types in Virtual Lab

Projects in the MMRF Virtual Lab fall into two primary categories:

### 1. IA24 (Final CoMMpass Release)

- Represents the final, fully harmonized CoMMpass dataset
- Contains:
    - Clinical data  
    - Summary-level data  
    - Processed genomic data  
    - Raw sequencing data  

This project is also the data source for the Analysis Center tools, enabling cohort building, visualization, and analysis.

---

### 2. Historic Interim Analysis (IA) Releases

- Includes IA11–IA22 releases  
- Each project contains:
    - **Summary-level flat files**
    - Release-specific documentation and outputs  

These projects are primarily used for:

- Accessing historical data cuts  
- Reproducing earlier analyses  
- Comparing across IA releases  

---

## Accessing a Project

### Step 1: Open the Projects Page

- Navigate to **Projects** from the top navigation bar or homepage

---

### Step 2: Select a Project

- Click a **Project ID** (e.g., *MMRF-COMMPASS-IA24*, *MMRF-IA22*)  
- This opens the **Project Summary Page**

---

### Step 3: Open the Repository

- On the Project Summary Page, click **View Files**  
- This opens the **Repository**, where all files associated with the project are stored  

---

## Project Summary Page

The Project Summary Page provides an overview of the dataset, including:

- Project metadata (Project ID, disease type, program)
- Total number of cases and files  
- Distribution of data across:
    - **Data Categories** (e.g., clinical, genomic)
    - **Experimental Strategies** (e.g., WGS, RNA-seq, CyTOF)

From this page, users can:

- Navigate to the Repository  
- Explore dataset composition before downloading  

---

## Repository Behavior by Project Type

### Historic IA Projects

- Repository displays a **limited set of summary-level files**
- Files are scoped specifically to that IA release  
- Minimal filtering is required  

---

### IA24 Project

Repository contains all data generated for CoMMpass, including:

  - Raw genomic data  
  - Processed outputs  
  - Summary datasets  
  - Clinical data tables  

Because of the large volume of files, filters should be applied to identify relevant datasets.

Common filters include:

- Data Category → Summary Data Files
- Data Category → Clinical Data Tables
